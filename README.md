# Colégio Dávilohn

Site em Next.js, publicado no hub com o slug `/colegio-davilohn` (ver `src/lib/base-path.ts`). Layout inspirado no template Altruist (https://altruist.framer.website/), com as cores do logotipo.

- Conteúdo: site antigo (colegiodavilohn.com.br), Instagram [@colegio_davilohn](https://www.instagram.com/colegio_davilohn/) e avaliações reais do Google Maps (`src/lib/data.ts`).
- Fotos otimizadas em `public/img`. Os originais ficam em `midia-original/` (fora do Git).

```bash
npm run dev   # http://localhost:3000/colegio-davilohn
```
